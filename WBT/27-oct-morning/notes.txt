types of modules:

1. predefined: already there in node js
2. user defined: developer
3. 3rd party module: a module given by another org, and we have to install them manually

   npm: node package manager 

   npm i/install module/package-name	

   npm uninstall module-name

note: when we install any 3rd party module there will always be a folder node_modules, 2 files : package.json, package-lock.json

package.json: a node application must always have a package.json 
it will be containing certain configurations related to the project
name, version, author, description, git repo, lic, main file/starting point etc

two types of 3rd party modules:

1. local module (dependency): module which is installed within a project/inside of a project 
	p1-express p2 p3
	
	a module which is providing a predefined code base in the form of functions, properties, classes etc etc, that has to be installed locally 

	npm i package-name 
	

2. global module: module which is installed globally somewhere in a shared location such that all the projects should make use of this global module

    npm i/install -g package-name
	
	a module/package which is providing a tool should be installed globally 
	
	npm i -g nodemon
