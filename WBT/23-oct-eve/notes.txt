JS has 3 keywords to declare the variable
var let const 

note: in the absence of any of the above keyword in the declaration then we cannot say that property is local or global, because that property will become the property of the window object even if it is declared inside the function also 

and we can access it everywhere 

var: we can specifically provide local or the global 

  var a = 5;

        function show(){
            
            console.log("inside show a=", a);
            
        }

        show();
        console.log("outside show a=",a);

        function show(){
            var a = 5;
            console.log("inside show a=", a);
            
        }

        show();
        console.log("outside show a=",a);


redeclaration is possible with the var keyword

     var a = 5;
        console.log(a);
        var a = 8;
        console.log(a);

for the variables declared using var keyword are getting hoisted 

JS engine first of all even before code execution, is going to read the entire src code and it will look for the declarations, and then it move all those declarations at the top of the code and then finally execution will be started 

This process is hoisting 

we have written this code:

  console.log(a);
    var a = 10;

but for js engine it is in this way:
var a;
 console.log(a);
 a = 10;

let: let keyword variables are having block scope

function show(){
        if(true){
            let x = 5;
            console.log("inside if x=",x); // only accessible inside if 
        }
        console.log("outside if x=",x); // not accessible here 
    }

    show();

using let keyword we cannot redeclare the variable

hoisting will be there for the let variables but there is rule that we cannot access let variable before their initialization 

const: is exactly same as let, but only the difference is that we cannot change the value of const variable
