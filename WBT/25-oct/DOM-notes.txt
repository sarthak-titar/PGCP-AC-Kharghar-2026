DOM -> Document Object Model 

Whenever a web page gets loaded in the browser, it will prepare a tree like structure for all the tags

document ->  its an object of the DOM


DOM Manipulation:

1. We can create a new element 
2. We can remove the existing elements
3. We can change the content of elements
4. We can get/read the content of elements 
5. We can change the style also
6. We can change the attribute value
7. We can get/read the attribute value

    <input type="password" placeholder="Enter Password" id="password-field">
    <button onclick="togglePassword()" id="btn">Show</button>

    <script>

        function togglePassword() {
            var passwordField = document.getElementById("password-field");
            var button = document.getElementById("btn");

            if (button.innerHTML === "Show") {
                passwordField.setAttribute("type", "text");
                button.innerHTML = "Hide";
            }
            else{
                passwordField.setAttribute("type", "password");
                button.innerHTML = "Show";
            }



        }


    </script>
</body>

        <input type="text" placeholder="Enter 2nd number" id="field-2">
        <button onclick="add()">Add</button>
        <h3 id="result"></h3>

        <script>
            function add(){
                var n1 = parseInt(document.getElementById("field-1").value); // string "3"
                var n2 = parseInt(document.getElementById("field-2").value); // "5"
                var n3 = n1 + n2;
                document.getElementById("result").innerHTML = "Sum is "+n3;
            }
        </script>
